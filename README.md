# 🌅 Утренний дайджест

Персональная стартовая страница для продуктивного утра — всё важное в одном месте.

## ✨ Возможности

| Блок | Описание |
|------|----------|
| 🕐 **Часы** | Живые часы с датой, приветствие меняется по времени суток |
| 🌍 **Погода** | Актуальная погода для Москвы, Владивостока или Ставрополя |
| ₿ **Биткоин** | Цена в USD и RUB, изменение за 24ч |
| 💱 **Курс валют** | USD/RUB и EUR/RUB от Центробанка РФ |
| ⚔️ **Квесты дня** | 3 случайных задания с RPG-системой XP и уровней |
| 🎭 **Афиша** | События города — Москва, Владивосток, Ставрополь |
| 😂 **Анекдот дня** | Меняется каждый день |
| 💬 **Цитата дня** | Мотивация по дням недели |
## 🚀 Быстрый старт

Просто скачай `index.html` и открой в браузере — никаких зависимостей и сервера не нужно.

```bash
git clone https://github.com/Cryptohawk3s/morning-digest.git
cd morning-digest
open index.html
```

## 🛠 Технологии

- Чистый **HTML / CSS / JS** — один файл, без фреймворков
- **Open-Meteo API** — погода (бесплатно, без ключа)
- **CoinGecko API** — курс биткоина (бесплатно, без ключа)
- **ЦБ РФ API** — официальные курсы валют
- **KudaGo API** — афиша Москвы
- **vl.ru** — афиша Владивостока
- **Telegram** @afisha_pro_stavropol — афиша Ставрополя
- **codetabs.com** — CORS-прокси для внешних источников

## 📦 Структура

